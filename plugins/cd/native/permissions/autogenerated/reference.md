## Default Permission

Everything the CD plugin's page needs: list drives, read discs, rip, cancel.

#### This default permission set includes the following:

- `allow-drives`
- `allow-disc`
- `allow-rip`
- `allow-cancel`
- `allow-backend-info`
- `allow-probe`
