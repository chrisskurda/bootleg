## Default Permission

Everything the Record page needs: list inputs, record, finish or cancel, analyse a recording, save tracks, discard a recording.

#### This default permission set includes the following:

- `allow-devices`
- `allow-record`
- `allow-finish`
- `allow-cancel`
- `allow-analyze`
- `allow-save`
- `allow-discard`
- `allow-recordings`
- `allow-backend-info`
